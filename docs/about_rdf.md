# RDF Тройка (Triple)

    Subject - Predicate - Object

Пример:

    wd:Q4232 wdt:P170 wd:Q1242

где:

    wd:Q4232 = Леонардо да Винчи
    wdt:P170 = создал (creator)
    wd:Q1242 = Мона Лиза


Субъект (Subject) → кто/что совершает действие

Предикат (Predicate) → что делает/какое свойство

Объект (Object) → результат действия/значение свойства

# RDF Четверка (Quad) 

По сути: Quad = Triple + "Где она лежит"

Это тройка с добавленной меткой контекста (имени графа):

- Субъект

- Предикат

- Объект

Граф (Graph) → "папка", где хранится этот факт

Пример:

    wd:Q4232 wdt:P170 wd:Q1242 <graph:Art>

где:

    wd:Q4232 = Леонардо да Винчи
    wdt:P170 = создал (creator)
    wd:Q1242 = Мона Лиза
    <graph:Art> = граф "Исскуство"
